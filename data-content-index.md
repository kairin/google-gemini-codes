# 🗂️ data/content-index Directory

The `data/content-index` directory contains generated JSON files that index your content, such as blog posts and projects. These files are typically created by build scripts and used for features like search, navigation, or content previews.

## What's Inside?

- 📝 `blog-first-post.json`: Metadata and index for the "First Post" blog entry.
- 📝 `blog-how-to-add-projects-online.json`: Metadata and index for the "How to Add Projects Online" blog entry.
- 📝 `project-astro-rebuild-guide.json`: Metadata and index for the "Astro Rebuild Guide" project entry.

## Purpose & Goals

- ⚡ Enables fast lookup and display of content metadata without parsing markdown files at runtime.
- 🔍 Supports features like search, filtering, and dynamic content lists.
- 📚 Keeps content metadata organized and accessible for the site.
