# 🐙 .github Directory (GitHub Configuration)

The `.github` directory contains configuration files for GitHub-specific features, such as issue templates and automated workflows.

## What's Inside?

- 📝 **ISSUE_TEMPLATE/**
  - `new-project.md`: Template for creating new project issues, helping standardize information collected when users open issues.
- 🤖 **workflows/**
  - `deploy.yml`: GitHub Actions workflow for deploying your site automatically when certain events occur (e.g., push to main branch).
  - `new-project-from-issue.yml`: Workflow to automate project creation or other actions based on new issues.

## Purpose & Goals

- 🧩 Standardizes issue creation for contributors.
- ⚡ Automates CI/CD and other project management tasks using GitHub Actions.
- 🤝 Improves project maintainability and collaboration.
