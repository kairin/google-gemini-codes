This page helps visualize and plan which components should be loaded at the top, middle, and bottom of each page. Use this as a checklist and planning tool for DRY, maintainable layouts.

Top of Page

  • Header / Navigation components
  • Any global context providers (if used)

Middle of Page

  • Page-specific content components (e.g., blog post, project details)

Bottom of Page

  • Any analytics or tracking scripts (if needed)

How to Use This Page
