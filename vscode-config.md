# ⚙️ .vscode Directory (VS Code Workspace Settings)

The `.vscode` directory contains settings and configurations specific to the Visual Studio Code editor for this project.

## What's Inside?

- 🧩 **extensions.json**: Recommends VS Code extensions to contributors for a consistent development environment.
- 🐞 **launch.json**: Defines debugging configurations for running and debugging the project within VS Code.
- 🏃 **tasks.json**: Custom tasks for building, running, or testing the project, which can be executed from the VS Code command palette.

## Purpose & Goals

- 🛠️ Ensures all contributors have a consistent and productive development setup.
- 🚦 Simplifies running, building, and debugging the project.
- 🚀 Improves onboarding for new developers.
